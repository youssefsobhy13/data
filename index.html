📖 ما هي SQL؟ lec5 - صفحة 3

تعريف SQL SQL إختصار لـ Structured Query Language، وهي لغة تستخدم للتعامل مع قواعد البيانات. هي اللغة الأهم والأكثر انتشاراً في قواعد البيانات الحالية.

معنى الاستعلام (Query) هو إنشاء جدول جديد يحتوي على نتائج معينة بناءً على شروط نحددها من الجداول الأصلية في قاعدة البيانات. الفرق بين الجداول الرئيسية (اللي بننشئها) والجداول المشتقة (اللي بتظهر نتيجة استعلام).

📌 أقسام SQL lec5 - صفحة 4
  • DDL (لغة تعريف البيانات) : تستخدم لإنشاء وتعديل وحذف الجداول والهياكل.
  • DML (لغة معالجة البيانات) : تستخدم لإدراج وحذف وتعديل واستعلام البيانات داخل الجداول.
  • DCL (لغة التحكم) : تستخدم لحماية قاعدة البيانات وتحديد صلاحيات المستخدمين.
🔹 مثال CREATE SCHEMA
CREATE SCHEMA COMPANY AUTHORIZATION 'Jsmith';

✅ شرح بسيط: الأمر ده بيعلن عن وجود قاعدة بيانات جديدة اسمها COMPANY والشخص المسؤول عنها هو Jsmith.

🔒 القيود (Constraints) lec5 - صفحة 14-17

القيود هي قوانين تمنع إدخال بيانات غلط.

  • NOT NULL : العمود ممنوع يكون فاضي.
  • DEFAULT : قيمة إفتراضية لو المستخدم مدخلش حاجة.
  • CHECK : شرط معين لازم البيانات تطبقه.
  • PRIMARY KEY : المفتاح الأساسي -> بيحدد كل سجل بشكل فريد وممنوع يكون NULL أو مكرر.
  • UNIQUE : يمنع تكرار القيم لكن يسمح NULL.
  • FOREIGN KEY : المفتاح الأجنبي -> بيربط جدول بجدول تاني.
أمثلة عملية
Dno INT NOT NULL DEFAULT 1;
Dnumber INT CHECK (Dnumber > 0 AND Dnumber < 21);
PRIMARY KEY (Ssn);
FOREIGN KEY (Dno) REFERENCES DEPARTMENT(Dnumber);
CREATE DOMAIN D_NUM AS INTEGER CHECK (D_NUM > 0);
🛠️ CREATE TABLE lec5 - صفحة 7-11

أمر CREATE TABLE بنستخدمه لإنشاء جدول جديد. بنحدد أسماء الأعمدة وأنواع البيانات والقيود.

جدول EMPLOYEE
CREATE TABLE EMPLOYEE (
    Fname VARCHAR(15) NOT NULL,
    Minit CHAR,
    Lname VARCHAR(15) NOT NULL,
    Ssn CHAR(9) NOT NULL,
    Bdate DATE,
    Address VARCHAR(30),
    Sex CHAR,
    Salary DECIMAL(10,2),
    Super_ssn CHAR(9),
    Dno INT NOT NULL,
    PRIMARY KEY (Ssn),
    FOREIGN KEY (Super_ssn) REFERENCES EMPLOYEE(Ssn),
    FOREIGN KEY (Dno) REFERENCES DEPARTMENT(Dnumber)
);
جدول DEPARTMENT
CREATE TABLE DEPARTMENT (
    Dname VARCHAR(15) NOT NULL,
    Dnumber INT NOT NULL,
    Mgr_ssn CHAR(9) NOT NULL,
    Mgr_start_date DATE,
    PRIMARY KEY (Dnumber),
    UNIQUE (Dname),
    FOREIGN KEY (Mgr_ssn) REFERENCES EMPLOYEE(Ssn)
);
جدول DEPT_LOCATIONS
CREATE TABLE DEPT_LOCATIONS (
    Dnumber INT NOT NULL,
    Dlocation VARCHAR(15) NOT NULL,
    PRIMARY KEY (Dnumber, Dlocation),
    FOREIGN KEY (Dnumber) REFERENCES DEPARTMENT(Dnumber)
);
جدول PROJECT
CREATE TABLE PROJECT (
    Pname VARCHAR(15) NOT NULL,
    Pnumber INT NOT NULL,
    Plocation VARCHAR(15),
    Dnum INT NOT NULL,
    PRIMARY KEY (Pnumber),
    UNIQUE (Pname),
    FOREIGN KEY (Dnum) REFERENCES DEPARTMENT(Dnumber)
);
جدول WORKS_ON
CREATE TABLE WORKS_ON (
    Essn CHAR(9) NOT NULL,
    Pno INT NOT NULL,
    Hours DECIMAL(3,1) NOT NULL,
    PRIMARY KEY (Essn, Pno),
    FOREIGN KEY (Essn) REFERENCES EMPLOYEE(Ssn),
    FOREIGN KEY (Pno) REFERENCES PROJECT(Pnumber)
);
جدول DEPENDENT
CREATE TABLE DEPENDENT (
    Essn CHAR(9) NOT NULL,
    Dependent_name VARCHAR(15) NOT NULL,
    Sex CHAR,
    Bdate DATE,
    Relationship VARCHAR(8),
    PRIMARY KEY (Essn, Dependent_name),
    FOREIGN KEY (Essn) REFERENCES EMPLOYEE(Ssn)
);

🔍 SELECT (الاستعلام) lec5 - صفحة 21-31

SELECT هو الأمر المستخدم لاستخراج البيانات من قاعدة البيانات.

أمثلة أساسية
SELECT Bdate, Address FROM EMPLOYEE WHERE Fname='John';
SELECT * FROM EMPLOYEE;   -- * تعني كل الأعمدة
SELECT Ssn FROM EMPLOYEE;

🔸 LIKE (البحث بنمط) : يستخدم مع علامة % (أي عدد من الحروف) و _ (حرف واحد).

مثال LIKE
SELECT FNAME, LNAME FROM EMPLOYEE WHERE Address LIKE '%Houston,TX%';

🔸 BETWEEN (بين قيمتين)

مثال BETWEEN
SELECT * FROM EMPLOYEE WHERE (Salary BETWEEN 30000 AND 40000) AND Dno = 5;

🔸 ORDER BY (ترتيب النتائج)

مثال ORDER BY
SELECT D.Name, E.Name FROM DEPARTMENT D, EMPLOYEE E ORDER BY D.Name, E.Name;

🔸 UNION (دمج نتيجتين)

مثال UNION
(SELECT Pnumber FROM PROJECT, DEPARTMENT, EMPLOYEE WHERE Lname='Smith')
UNION
(SELECT Pnumber FROM PROJECT, WORKS_ON, EMPLOYEE WHERE Lname='Smith');

📖 What is SQL? lec5 - page 3

SQL Definition SQL stands for Structured Query Language. It is the most widely used database language in current databases.

The Query A query is creating a new table that contains results with specific criteria from the database tables. There is a difference between main tables (original) and derived tables (query results).

📌 SQL Divisions lec5 - page 4
  • DDL (Data Definition Language): Used to create/alter/delete tables and their attributes.
  • DML (Data Manipulation Language): Used to insert/delete/modify/query data in records.
  • DCL (Data Control Language): Used for database protection and security.
🔹 CREATE SCHEMA Example
CREATE SCHEMA COMPANY AUTHORIZATION 'Jsmith';

✅ Simple Explanation: This command declares a new database named COMPANY and the responsible user is Jsmith.

🔒 Constraints lec5 - page 14-17

Constraints are rules that prevent wrong data entry.

  • NOT NULL : Column cannot be empty.
  • DEFAULT : Default value if user doesn't provide one.
  • CHECK : A condition that data must satisfy.
  • PRIMARY KEY : Uniquely identifies each record, cannot be NULL or duplicated.
  • UNIQUE : Prevents duplicate values but allows NULL.
  • FOREIGN KEY : Links one table to another table.
Practical Examples
Dno INT NOT NULL DEFAULT 1;
Dnumber INT CHECK (Dnumber > 0 AND Dnumber < 21);
PRIMARY KEY (Ssn);
FOREIGN KEY (Dno) REFERENCES DEPARTMENT(Dnumber);
CREATE DOMAIN D_NUM AS INTEGER CHECK (D_NUM > 0);

🔍 SELECT (Data Retrieval) lec5 - page 21-31

SELECT is the command used to extract data from the database.

Basic Examples
SELECT Bdate, Address FROM EMPLOYEE WHERE Fname='John';
SELECT * FROM EMPLOYEE;   -- * means all columns
SELECT Ssn FROM EMPLOYEE;

🔸 LIKE (Pattern Matching) : Uses % (any number of characters) and _ (single character).

LIKE Example
SELECT FNAME, LNAME FROM EMPLOYEE WHERE Address LIKE '%Houston,TX%';

🔸 BETWEEN (Between two values)

BETWEEN Example
SELECT * FROM EMPLOYEE WHERE (Salary BETWEEN 30000 AND 40000) AND Dno = 5;

🔸 ORDER BY (Sorting Results)

ORDER BY Example
SELECT D.Name, E.Name FROM DEPARTMENT D, EMPLOYEE E ORDER BY D.Name, E.Name;

🔸 UNION (Combine Two Results)

UNION Example
(SELECT Pnumber FROM PROJECT, DEPARTMENT, EMPLOYEE WHERE Lname='Smith')
UNION
(SELECT Pnumber FROM PROJECT, WORKS_ON, EMPLOYEE WHERE Lname='Smith');
